## กติกาการเตรียมภาพ

- การชี้แจงล่าสุดของผู้ใช้แทนคำกำกับเดิม “Fennec”: ภาพที่ 6 คือเรื่องเด็กกับแมว / ห้องเล่นกับแมว ไม่ใช่ภาพเฟนเนก การนำเสนอห้องแมวเป็นส่วนหนึ่งของกลุ่ม Indoor ตามบริการเดิม ไม่เพิ่มจำนวนโซนหรือราคาเอง

- ต้นฉบับทุกภาพมีตราร้านมุมบนขวา เก็บต้นฉบับไว้เสมอ การจัด crop ต้องไม่ทำตราขาดครึ่งหรือทับหน้าสัตว์ ตรวจภาพขนาดใช้งานจริงก่อนเลือก
- เริ่มจาก responsive crop / object-position และ web encoding ใช้ภาพในขนาดที่ความละเอียดรองรับ รูปสี่เหลี่ยม 1080 px ไม่ควรถูกบังคับเป็น hero กว้าง 1920 px; hero หลักยังเป็นวิดีโอ
- ภาพที่ 1 มีข้อความซ้อนกับพื้นที่ที่เล่า interaction การ crop อาจตัดเรื่องสำคัญออก ถ้า crop ไม่ดีพอให้ใช้ภาพอื่นในช่องหลักและบันทึกว่าต้องการต้นฉบับไม่มีข้อความ ไม่สร้างภาพกิจกรรมใหม่ขึ้นมาแทนหลักฐานจริง
- ถ้าต้องลบข้อความด้วยเครื่องมือแก้ภาพในภายหลัง ให้เก็บเป็น derivative แยก ระบุวิธีและขอบเขตการแก้ และตรวจว่าคน สัตว์ รั้ว และสถานที่ไม่ได้เปลี่ยนอย่างมีนัยสำคัญ ห้ามอ้างว่า derivative เป็นภาพต้นฉบับที่ไม่เคยแก้
- ภาพที่มีคนไม่ใช้สรุปว่าทุกคนสัมผัสหรืออุ้มสัตว์ได้ทุกตัว ทุกเวลา คำบรรยายต้องไม่ขยายสิทธิประโยชน์เกินเมนูบริการ
- ไม่ใส่ภาพใหม่ทั้งหกเพียงเพื่อให้ครบ เลือกตามหน้าที่ของเรื่องและจังหวะหน้า ลดการใช้ภาพเดียวซ้ำใน section ที่อยู่ติดกัน
