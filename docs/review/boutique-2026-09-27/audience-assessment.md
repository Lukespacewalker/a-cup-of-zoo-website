## ช่องว่างภาษาอังกฤษในเส้นทางหลัก

| เส้นทาง | สิ่งที่ยังขาด |
| --- | --- |
| รู้จักร้าน/สัตว์ | คำอธิบายร้าน ทำเล สิ่งที่ทำได้ ชื่อกลุ่มสัตว์ และ navigation/ปุ่มหลักภาษาอังกฤษ |
| เมนูและราคา | หมวด ชื่ออาหาร 47 รายการ คำอธิบาย ตัวเลือกโปรตีน/ไส้เพิ่ม และหน่วยสกุลเงินที่อ่านเข้าใจได้ เช่น THB โดยคงค่าราคาเดิมทุกตัวเลือก |
| แพ็กเกจและเงื่อนไขเด็ก | สิ่งที่รวม/ส่วนลดของแต่ละแพ็กเกจ การมาคาเฟ่โดยไม่ซื้อแพ็กเกจ ขั้นต่ำต่อคน เงื่อนไขความสูง ผู้ใหญ่ร่วมกิจกรรม ถุงเท้า และ Outdoor 18:00 รวมคำแนะนำการดูแลเด็ก/สัตว์ |
| เวลาเปิดและการเดินทาง | ชื่อวัน วันปิด ข้อยกเว้นวันหยุดนักขัตฤกษ์ ที่อยู่ FAQ และชื่อปุ่ม Maps/โทรศัพท์ภาษาอังกฤษ แม้ตัวเลขเวลาและเบอร์โทรมองเห็นได้อยู่แล้ว |
| การใช้งานตลอดเส้นทาง | ตัวเลือกภาษาและหน้าที่เชื่อมต่อกัน รวมชื่อปุ่ม/ชื่อสำหรับเทคโนโลยีช่วยอ่าน และการประกาศภาษาของหน้าให้ตรงกับเนื้อหา |

ลำดับงานต่อที่มีผลกับลูกค้ามากที่สุดคือเส้นทางอังกฤษทั้งชุดข้างต้น โดยรักษาค่าใช้จ่าย/ข้อยกเว้นเดียวกับไทย แล้วตรวจการตัดบรรทัดและการกดบนมือถือใหม่ รอบนี้เป็นการประเมินและบันทึกช่องว่างตามคำสั่ง ยังไม่ได้สร้างฉบับอังกฤษหรือแก้ CMS

## ราคาและการสื่อคุณค่า

- Catalog และภาพอาหารต้นฉบับไม่เปลี่ยนจาก HEAD ที่รวมงานนำเข้าไว้ ข้อมูลราคาไม่ได้แก้ในงานธีม
- ตรวจ render สดพบ 47 รายการ เปรียบเทียบราคาในแถวอาหารกับทุก Offer ของ Menu JSON-LD แล้วตรงกัน รวมตัวเลือกหลายราคา หลักฐานใน `audience-observations.json`
- แสดงภาพอาหารต้นฉบับให้เห็นจานจริง คู่ชื่อ/รายละเอียด/ราคา และแสดงภาพสวน มุมนั่ง และสัตว์จริงเพื่อช่วยให้ลูกค้าเห็นประสบการณ์ของสถานที่ แพ็กเกจแยกสิ่งที่รวมอย่างชัดเจน
- ไม่ใช้คำอ้างวัตถุดิบพรีเมียม ออร์แกนิก มาตรฐานความปลอดภัย การดูแลเด็กโดยพนักงาน หรือความสามารถภาษาอังกฤษของพนักงานเมื่อไม่มีหลักฐาน และไม่แต่งราคาเครื่องดื่ม/ขนมที่ยังไม่มี

## วิธีตรวจและขอบเขตหลักฐาน

Root เป็นผู้ทำธีมและผู้ประเมินสี่ด้านนี้ ใช้ภาพ render ชุดสุดท้ายที่ hash ยังตรงกับ `review-target.json` ทั้งหมด ทบทวนภาพ light/dark ที่ 390/1440 px และใช้ BrowserOS neo อ่าน DOM/กดปุ่มหน้าแรกไปเมนูจริงรอบนี้

รัน `node docs/review/boutique-2026-09-27/audience-check.mjs` ด้วย Playwright Chromium, locale `en-US`, 390×844 px: เปิดหน้าแรก/สัตว์/เมนู/กิจกรรม/visit ตรวจภาษา กดเมนู กระโดดหมวด เปิดภาพอาหารเพิ่ม และกดมาเที่ยวต่อไปแพ็กเกจ/เงื่อนไขเด็ก **ผ่าน** ตรวจราคา render ตรง schema ทั้ง 47 รายการ **ผ่าน** และยืนยันว่าเส้นทางยังเป็นภาษาไทย

สคริปต์ probe รอบแรกจับชื่อแบบ substring ทำให้ซุปครีมเห็ดไปจับแถวซุปครีมเห็ดพร้อมครัวซองต์ จึงแก้เฉพาะการจับชื่อให้ตรงเต็มชื่อและรันใหม่ผ่าน ไม่มีการแก้ข้อมูลหรือราคาของเว็บ

ผล unit 17/17, E2E 18/18, check/build และผู้ตรวจแยก PASS ใช้หลักฐานชุดสุดท้ายของงานธีมตาม [รายงานเดิม](README.md) ไม่อ้างว่าได้รันชุดทั้งหมดซ้ำในรอบประเมินที่ไม่แก้ product code การตรวจอังกฤษครั้งนี้เป็นของ Root และยังไม่ได้ทดสอบกับลูกค้าหรือ CMS/production จริง

ทบทวนแนวทาง semantic links, focus, motion, typography และ locale จาก [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) ประกอบการตรวจ โดยไม่ได้อ้างว่าผ่านทุกข้อของ guideline หรือวัดคะแนน performance แล้ว
